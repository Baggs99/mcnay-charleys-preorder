# McNay & Charlie's PreOrder

A lightweight preorder web app for McNay's Cafe and Charlie's Place at Yale SOM.

## What It Does

- Browse sample items from both cafes.
- Add items to a cart.
- Select a pickup spot and pickup time.
- Review a simple order summary.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
